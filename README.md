# 薄荷启动器 · MintLauncher

一个独立的 Minecraft: Java Edition 启动器项目，当前处于功能预览阶段。

**非官方 Minecraft 启动器。未经 Mojang 或 Microsoft 认可，亦与其无关联。**

目前支持原版版本获取与安装、离线启动、导入现有 `.minecraft` 目录，以及部分 Fabric 实例修复。微软网页登录流程已实现，但本项目的应用 ID 尚未获 Minecraft Services 接受，当前正版登录会在服务端返回 `Invalid app registration`；请勿将本仓库视为已完成正版登录的正式发行版。

构建需要 Windows 和 .NET 10 SDK。项目代码在 [`MintLauncher/`](MintLauncher/)，详细功能与限制见[项目说明](MintLauncher/README.md)。仓库按 GPL-3.0 发布；第三方依赖声明见 [`THIRD_PARTY_NOTICES.txt`](MintLauncher/THIRD_PARTY_NOTICES.txt)。本仓库不包含游戏本体、下载缓存、用户账户数据或授权未确认的第三方皮肤图片。
